Phase 1
Implementasi Segmentasi (SegFormer-B5)

Load SegFormer-B5 dari HuggingFace. Jalankan inferensi → dapat pixel map per kelas. Dari pixel map, hitung 5 metrik: green_coverage, building_coverage, sky_visibility, walkability_ratio, visual_clutter_index. Simpan output ke database.

Phase 2
Implementasi Feature Extraction (DINOv2 Large)

Load DINOv2 Large dari HuggingFace. Jalankan pada foto → ambil embedding vektor (1024 dimensi). Tidak perlu fine-tuning. Gabungkan embedding ini dengan 5 metrik segmentasi → jadi 1 feature vector per foto untuk input XGBoost.

Training XGBoost & evaluasi R²

Train 4 model regresi terpisah: Beauty, Safety, Comfort, UVI. Gunakan K-Fold cross-validation. Pastikan R² ≥ 0.7 pada data validasi. Jika belum mencapai 0.7, coba feature engineering atau tambah data kuesioner.
