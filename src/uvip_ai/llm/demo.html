UVIP-AI — LLM gateway (9router)

Halaman ini disajikan oleh API utama di — lihat juga /docs. Semua path relatif, jadi jalan di host/port apa pun.

Endpoint

GET  /llm/ask?q=...&model=...&system=...   -> text/plain (jawaban mentah)
GET  /llm/chat/completions?q=...           -> JSON OpenAI-shape + context
GET  /llm/models                           -> daftar model upstream
GET  /llm/health                           -> status upstream
POST /llm/chat                             -> chat multi-turn (body JSON) -> JSON
POST /llm/chat/completions                 -> passthrough (stream jalan)
POST /llm/vision                           -> analisa gambar (multipart) -> JSON
POST /llm/advise                           -> foto + metrik -> rekomendasi + prompt gambar
