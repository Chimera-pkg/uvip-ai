UVIP-AI — LLM gateway (9router)

Halaman ini disajikan oleh API utama di — lihat juga /docs. Semua path relatif, jadi jalan di host/port apa pun.

Endpoint

GET  /llm/ask?q=...&model=...&system=...   -> text/plain (jawaban mentah)
GET  /llm/chat/completions?q=...           -> JSON OpenAI-shape + context
GET  /llm/models                           -> daftar model upstream
GET  /llm/health                           -> status upstream
POST /llm/chat                             -> chat multi-turn (body JSON) -> JSON
POST /llm/chat/completions                 -> passthrough (stream jalan)
POST /llm/vision                           -> analisa gambar (multipart) -> JSON
POST /llm/advise                           -> foto + metrik -> rekomendasi + prompt gambar
GET  /ai/scoring/schema                    -> definisi slider, bobot, anchor, skala
POST /ai/scoring/preview                   -> 8 indeks -> skor (tanpa model ML)
POST /ai/scoring/evaluate                  -> sebaran skor seluruh dataset (431 foto)
GET/POST/DELETE /ai/scoring/profiles[/{name}] -> profil tuning tersimpan

Uji advise (POST /llm/advise)

Otomatis = AI memberi rekomendasi seimbang. Manual = geser 5 bobot di bawah untuk memprioritaskan dimensi tertentu, lalu klik lagi untuk regenerate. Setelah "Proses" di panel bawah, kotak metrik & skor otomatis terisi dari foto itu. 

—

Uji proses foto (POST /ai/process)

Profil diambil dari panel tuning di bawah; bila kosong, slider yang sedang aktif dikirim sebagai tuning inline. Segmentasi GPU bisa 20-80 detik. 

—

Tuning skor (PVI v1)

Ubah bobot/rentang, cek sebaran pada 431 foto, simpan sebagai profil, lalu pakai di /ai/process atau /ai/advise lewat field profile. Tanpa model ML - hanya aritmetika indeks.

Nilai awal kotak indeks = contoh median. Setelah tombol "Proses" di panel atas, kotak ini otomatis berisi 8 indeks foto yang baru diproses.
